Lists every image in assets/img/gallery/ automatically, so adding a photo needs no change to this file — drop it in, push, done. site.static_files is core Jekyll, not a plugin, so this works on GitHub Pages. Filenames are ginger-YYYY-MM-DD.jpg, which makes a plain name sort chronological. Captions are optional and come from _data/gallery.yml, keyed by filename. {%- endcomment -%} {%- assign photos = site.static_files | where_exp: "f", "f.path contains '/assets/img/gallery/'" | sort: "name" -%} {%- if site.gallery_newest_first -%} {%- assign photos = photos | reverse -%} {%- endif -%} {%- if photos.size > 0 -%}
